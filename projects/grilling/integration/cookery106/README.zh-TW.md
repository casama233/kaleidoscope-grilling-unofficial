# A1.13 — 森羅物語：煙火 玩家指南

本包只負責把「煙火」作為一個章節接入 Cookery 1.0.6 原有指南，不新增第二本指南書。

A1.13 把早期「素材預覽／來源參考」頁改為玩家實際使用的指南：

- 正式名稱：森羅物語：煙火 / Kaleidoscope Grilling。
- 三個清楚分類：玩法與取得方式、烤串食譜、調料與效果。
- 玩法頁使用不同實物圖標，不再所有按鈕重複同一根烤串。
- 說明改成操作步驟，不再顯示 source id、開發狀態或中英混排的測試文字。
- 20 組固定串仍依 Java 1.1.1 的順序顯示。
- 指南內容已更新到目前 Gameplay Core 已完成的串盤、串譜、榨油器、大缸、四種作物與紅辣椒粉加工鏈。

Cookery 1.0.6 的 Guidebook Extension API v1 對 mechanics 的 locale 有已知限制，因此正文仍使用單一中文 fallback；分類名、標題與條目名稱會正常跟隨 zh_CN / zh_TW / en_US。

這仍不是 Minecraft/BDS 實機驗收聲明；UI 尺寸、觸控與控制器顯示需要遊戲內再確認。
