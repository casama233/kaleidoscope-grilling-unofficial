# 森羅物語：煙火 — 指南 A3.0

這是 Cookery 既有指南的煙火擴充，不是另一本文字書，也不包含煙火 Gameplay Core 或 Cookery 本體。

## 開啟與更新

啟用既有 Cookery 本體、煙火 Gameplay Core，以及本套指南 BP/RP；本套兩個包版本皆為 0.3.0。
退出世界後重新載入，再從 Cookery 的指南物品進入「森羅物語：煙火」。不會新增另一件實體指南書。
沿用原指南 BP/RP UUID，請更新本套指南，不要只重新安裝 Gameplay Core；沒有更改原世界物品 ID 或資料格式。
原版 Cookery 1.0.6 的指南 locale validator 有既有相容限制，沿用先前的窄範圍 locale-compat 版本／流程。本指南包不會自動改寫 Cookery。

## 六個分類

- 工作站：燒烤架、榨油器。
- 食物百科：燒烤架、手工穿串、炒鍋、湯鍋、合成與加熱、砧板、磨石、食材與其他食物。
- 工具與裝備：調料瓶與特製調料、煙火油壺操作。
- 儲存與實用功能：高級廚具架、盤子、大缸、油桶／油壺。
- 耕作與收成：作物、花椒樹、採收與油渣。
- 進度與指南物品：串譜、首次燒烤流程、煙火氣與活動喜糖。

## 看條目的方式

每項集中說明取得、製作、用途、操作條件與效果。
固定烤串的生熟資訊在同頁；可從「手工穿串」或「燒烤架」打開同一條目。營養主面板為熟串，正文另外列出生串比較。
空瓶、半成品和完成調料也是同一流程頁，不必在三個同名頁面之間跳轉。
一般配方用本體的材料／成品顯示；有序工作台配方保留九宮格文字，穿串則保留食材先後順序。

未核實的生存取得途徑會明示，不列猜測配方。酸辣粉需要酒館醋；喜糖有活動時間限制。
76 個唯一條目、77 個配方變體；三語內容跟隨本體指南語言。
