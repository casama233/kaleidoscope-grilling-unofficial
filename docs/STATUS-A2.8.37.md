# A2.8.37：油壺共用、權威出料與沉浸修復

本輪從已合併的 2.8.36 整合，保留餐盤交易／朝向及 2.8.32 的 Java 廚具架物品圖示；不覆蓋並行工作的提交。指南為 0.3.11、publisher `a3_0_11`。發布與部署狀態以實際家族收據為準。

- 作者與煙火共用公開油壺協議，保持油種、容量、點數、資料與舊物品遷移。普通油 256、三種 typed 油 64；刷油後作者與煙火讀同一剩餘量。副手能力由受 hash 鎖定的微型 API 宣告補上。
- 油壺放置、補油、耗盡與回收不再變成 256 點普通油。混油／無效資料拒絕；炒鍋扣油與保存、整疊空桶及世界油源建立有讀回與故障回復。
- 作者出料攜帶公開 heat/seasoning，保留可疑燉湯原生變體。領料、容器交付及完成炒鍋破壞回收有持久 operation ID，未知交付停止補發。
- 作者食品公開登記效果、轉換容器、額外容器與辣椒傷害，秘製串明確繼承已登記行為；不同調味的熱食不合併。
- 廚具架九槽與餐盤五槽顯示實際物品類型；秘製串在設備上顯示其三個食材及竹籤。顯示副本不是物品儲存／交付權威。未知第三方原生資料模型仍需其公開 render 介面。
- 餐盤破壞、支撐移除及爆炸由持久交付收據保護，先保存內容，確認掉落後才清資料。未知投放隔離、禁止重複補發；創造模式不掉獎勵。
- 將 Java 五種取食曲線轉成原有手持骨架上的物品動作；進食期間顯示 1.25 秒門檻與熱度符號。只由既有 interaction feedback 模組寫 Actionbar，無常駐準心 HUD。
- 龍血有限額外生命池保留耗盡的零值；同 tick 傷害預留及延後可寫入環境提交避免無限補盾。原生生命提升加 4／8、額外池 2，邏輯總額 6／10，升級只補差量。
- 指南沿用廚房六個根類、分組／物品頁／Preparation；修正牛肉塊與雞皮可取得狀態、副手步驟及三語製程／材料名稱。原版音效與烹調貼圖保持已修版本。

[API 回饋稿](COOKERY-FAMILY-API-PROPOSAL.md) 與 [逐項差距](PARITY-REPAIR-MATRIX.md) 記錄功能及界線。基岩 stable API 沒有 Java 任意 NBT 驅動物品外觀、原生第一人稱雙手取食／第二截模型、同等 FluidType、Java 選用模組或動態背包熱圖框；這些不得寫成已完全移植。`THREE_RANDOM` 的伺服器音訊／咬食分支保留随机，attachable 預設 THREE 曲線，仍需可跨包同步的客戶端參數才能與隨機分支逐次一致。

所有儲存故障測試、獨立原生 BDS、實際存檔遷移及真人客戶端驗收分開記錄。使用者已要求先部署 live 供驗收；這不會將 client 證據改成 true。完整流程的 BDS proof 驗證原生儲存和 canonical 處理函式，不是自動玩家生存遊玩。
