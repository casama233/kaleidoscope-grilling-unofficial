## Identity and permission are separate

Explicit aliases precede a same-name fact. Native full `snow` uses original
`snow_block` true; Native `snow_layer` uses original `snow` false. Native
`stone_stairs` uses the cobblestone family, while `normal_stone_stairs` uses
the original stone family. Matching names alone would misclassify the full
snow block. Finite legacy/later rename and slab-family evidence is recorded
with each original branch and pinned Native serialization provenance.

The bounded ordinary batch requires an actual Native registered namespace ID
equal to the real registered ID in **both** original versions, exact official
English identity in both, and congruent original all-state motion. Native
serialization text is bound to the pinned label lookup as provenance; it
never constructs a Java identity. Labels identify a concept and never supply
motion. The actual original predicate supplies every Boolean. Explicit
aliases and known composite exclusions take priority over this batch.

The fixture retains all1,032 corrected diagnostic facts. Seventy-five facts
have no accepted identity proof; three additional facts have a qualified
identity but lack one original branch. All60 original21-only facts remain
unusable by the default two-branch consumer, including those overlapping
identity holds. The431 unmatched Native identities remain unknown. The
catalog does not infer solid/air from a name, material, opacity, ray or native
solidity flag. Global semantic review remains false.

The eligibility rule is source preparation, not release admission. Native
permutation products, exact shapes, event phases and client behavior remain
separate requirements. Addons overriding a known ID/state without observable
changes are outside the declared vanilla-definition contract.

## Read-only column contract

The unchanged resolver floors all three sample coordinates into an integer
cursor while retaining a separate double workingY. It checks the starting
chunk before reads. While cursorY is above the original minimum it reads the
cell below: false decrements double Y by exactly1 and advances the cursor;
true returns sampled double x/z and current double Y without an extra step.
No floor at the minimum is a supported failed attempt. Unknown, unloaded,
throwing, changed-context or out-of-domain cells stop as unsupported.

The exact finite bound is `max(0,floor(sampleY)-originalMinimum)`, with the
existing author clamps giving383/127/255 cells for Overworld/Nether/End.
There is no shorter ray/work cutoff. Identity and all states come from one
native permutation snapshot, and the actor context is rechecked.

The integrating caller checks `supported && found`, then perform
the existing full-body liquid check at the **adjusted** destination before
native collision/teleport. The resolver owns no movement, fee, rider exit,
audio, feedback, navigation stop or game event. The caller explicitly retains Native velocity. Complete projectile impact
phases, collision shape and client behavior remain separate work.
