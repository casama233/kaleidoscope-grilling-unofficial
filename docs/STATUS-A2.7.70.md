# A2.7.70 — 放置調料瓶內容與油壺油種外觀

接續 A2.7.69，整合此前仍在 PR 的烤串、手持調料、PBR、格言與油壺交易修復。保留現有物品／方塊、Cookery 1.0.6 依賴、所有包 UUID 及容器儲存鍵，不把外觀助手當容器。

## 放置調料瓶

原本五種放置方塊只有玻璃外殼。本版依 `SeasoningBottleRenderer.OFFSETS` 對每瓶獨立顯示内容：完成調料使用與 A2.7.66 手持版相同的 8 種外觀和 8 級剩餘量；剩餘級別沿用 Java `(16-uses+1)/2` 的整數分組。未完成調料按配料順序顯示最多 8 層，取自固定 Java 最大填充模型的 16 個 tintindex 面群組，而不是把整瓶塗成單色。

填料 geometry 去掉手持綁定並回到方塊座標，不重複畫原有玻璃外殼。疊瓶、取瓶、加料、破壞、舊世界重新載入，都從既有 `sb_` 資料重建顯示。完成瓶保留獨立的 variant/uses，不把頂瓶的外觀套到其他三瓶。

## 放置油壺

Java 根據油種類型切換壺身貼圖；極品辣椒油使用秘制辣椒油皮膚再加發光層。本版以固定 Cookery Java 壺體模型及 Grilling 原始皮膚貼圖製作獨立顯示層，跟隨方塊朝向。空油壺／原生油脂不添加類型皮膚。沒有替換 Cookery 方塊、修改碰撞、油量、容量、掉落或交互。

皮膚外推 0.01 模型單位、發光層外推 0.02 模型單位，以減少與宿主幾何共面閃爍；這是明示的 Bedrock 顯示適配，不是 Java blockstate 本體。原版 `oil_pot_premium_glow` 模型引用在固定來源中缺檔，因此發光 PNG 套用相同壺體面配置。宿主 Bedrock 1.0.6 的實際幾何／朝向與此 Java 幾何覆蓋對齊仍需實機確認，不能由靜態測試宣稱 1:1。

## 顯示生命周期

兩種助手均為 `minecraft:transient`、零碰撞、無掉落／背包／交互，卸載便消失。助手只保存可丟棄的 client_sync 顯示屬性，不保存玩家配料或油量。來源寫入成功及回復時通知顯示佇列；重進世界從既有儲存鍵索引重建；48 格外不保留助手，更新每五 tick 限額 12 個容器，總顯示助手上限 1024。超過上限只延後顯示，不改內容。每 400 tick 有分批的鍵索引校正，處理外部匯入資料；不扫描世界方塊。

## 明確限制

配料顏色沿用 Java 中央半區兩個主要色規則，對目前模組包內可解析的 item atlas 於建置時取樣。無可解析來源／外部配料使用 Java 的既定雙色後備值。沒有聲稱能於伺服器讀到每位玩家的第三方材質包或任意 host particle sprite，所以動態第三方換皮仍不是 Java 即時取樣的 1:1。

本版是新增實際 renderer 與同步生命周期，不是只加檢查器；但 `minecraft_tested=false`、`bds_tested=false`、`client_visuals_tested=false`。需要備份世界確認透明排序、油壺宿主對齊、極品光層、多人重載與性能。正式合併不等於實機驗收；發布包保持 prerelease。
