# A2.8.10：餐盤、搖勻瓶與指南修復

基線：main `7ef78bb`（A2.8.7）；現行 luosen BP 2.8.9 / RP 2.8.7。這是獨立修復分支，不宣稱尚未合併的 A2.8.8 候選 PR 已整合。

## 本批修改

1. **餐盤結算**：移除沒有開始使用記錄的 fallback。核對原物品完整資料、主副手及槽位；容許原生食用已消耗單件餐盤後的空手狀態。先建好並驗證剩餘餐盤，先寫物品，再給營養；失敗回復餐盤、飢餓及飽和，成功後才給效果與成就。
2. **搖勻瓶**：保存開始使用的瓶子與手別，不再按物品 ID 猜手。換槽、換配料瓶、重複完成事件及寫入失敗不給成品／成就；取消與離線釋放暫存。
3. **單一指南**：server-edition 原本同時發布舊精簡版和新版 76 條目指南，source/module ID 相同。移除舊 publisher，原封保留 canonical `scripts/guide/` 與繁中、簡中、英文。
4. **打包器**：`--version` 現在寫入兩個 manifest、modules 及 BP→RP 依賴；私服 Cookery 明確為 1.0.7。保留已裝 20 項方塊連接規則、5 項自然欄分類、共享創造欄圖示與穩定 ItemStack 資料適配。
5. **狀態文件**：修正 README、修復總表的過時版本；保留 A2.8.7 的 107 attachable、39 串骨架及 43 項植物材質修復。

- `verify_current.py`：保留所有 A2.8.7 舊 gate，加上 server-edition 實際生成、單一指南／三語原檔、版本與相容設定檢查。
