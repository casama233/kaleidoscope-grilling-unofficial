# A2.8.31：Java 砧板材料取得

Grilling canonical runtime 提供可審查的 Board API 0.1.0 模組與兩個配方。家族組裝器在指定 Cookery 1.0.8 作者原檔插入 API 呼叫點，原作者身份及版本不變；組裝收據明確標記 upstream_extended，列出原檔／改後 hash、owned commit、獨立 API 版本及到期條件。

- 生牛肉：4 刀，再一次使用釋出 2 份牛肉塊；符合 Java raw_cow_offal 配方替代。
- 生雞肉：4 刀，再一次使用釋出原主產物 2 份碎肉，加上均勻隨機 1～3 片雞皮。殺雞仍只按既有邏輯掉雞翅。
- 四刀消耗刀具耐久；釋出不加第五次耐久。音效、粒子及模型由原廚房砧板處理。
- 潛行取消、破壞及爆炸只退回原料，不給副產物；保留原料名稱與 lore。
- 配方方案及副產物取樣寫入砧板狀態，完成產出寫入獨立持久收據。已確認產出不重複釋出；未確認的原生投放中斷隔離供核對。
- 其他砧板配方仍走作者處理。未安裝完整家族 API 的普通 Cookery 1.0.8 不會自行取得新材料；共用指南說明此依賴。

來源回饋提案：[COOKERY-BOARD-API-PROPOSAL.md](COOKERY-BOARD-API-PROPOSAL.md)。原作者的完整私有腳本不進本倉庫，翻譯包不承載功能修補。API 擴充於 2026-11-02 到期，作者版提供等效能力後移除。

原生 BDS、完整串流程及正式存檔演練的機器證據存放於部署收據；真人畫面與操作驗收由 live 完成，不能由儲存操作測試代替。
