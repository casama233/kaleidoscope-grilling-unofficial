# 2.8.54 — 原生進食時間與手持動畫修復

隨機三口進食以前在使用開始後才決定動畫，導致 THREE_ALT 的 90 tick 動畫／進度配上固定 100 tick 的原生食物。現在在手持且尚未使用時選定原生 90／100 tick 版本；開始事件依實際物品選 profile，原生完成保留唯一扣料路徑。內部版本沿用原名稱、模型、食物組件與物品資料；料理、調料、原生合成標籤、盤子、秘製串及展示查詢解析回 canonical 食物身份。

恢復 Java 的 25 tick 放手 checkpoint 及一 tick 釋放容差。原有物品身份、選槽、熱度自然到期及 start／stop／complete 的重複結算保護保留。

手持食物運動改為 Java arm／item 矩陣組合後轉換到既有手持骨架，包含獨立 item rotation／translation；不再直接相加不同座標系的 Euler 曲線。Java 第一人稱 renderer 的自訂物品運動僅在第一人稱生效，第三人稱維持原生使用動作與 bite stage，避免把相機空間路徑加到第三人稱物品。既有閒置手持框架及原始 mesh／UV 不改動。

進食音效仍依 Java 只播給使用者；初次播放拒絕會留下紀錄，且在同一有效使用階段最多三次嘗試。交易不因聲音失敗而中止。

包／模組 2.8.54、指南 0.3.23／revision kg-guide-a3-2854、相依與 release-history 必須同步。完整家族載入／存檔准入及真人第一／三人稱、音效實聽仍為獨立證據。此版未聲稱完整雙臂／副手食物 renderer 或所有客戶端消失情境已驗收；client=false、production_ready=false。

內部進食版本在秘製串展示、固定串料理與配料查詢一律解析 canonical 身份；2.8.52／2.8.53 為未部署的候選，歷史收據保留。

秘製串的重複配料比較使用 canonical 身份，避免同一食物的內部進食版本被算成不同配料；原始 native snapshot 仍保留以供取回。
