# Guide A1.13 — 玩家指南整理

這一批只處理使用者實機截圖中的指南問題，不改燒烤玩法核心。

## 問題

舊 A1.12 是「素材／指南接入測試」時期的資料，所以即使能進 Cookery 1.0.6 指南，內容仍有幾個明顯不適合正式玩家的地方：

- 章節名仍是「煙火 · 素材預覽」。
- 類別名稱含「來源參考」「開發中」等開發標記。
- 多個按鈕重複使用同一個燒烤架圖示，無法一眼分辨。
- 配方頁直接顯示 Java source id、tag 與中英混排。
- 榨油器、大缸、作物、串盤、串譜等後來已完成的玩法，說明仍寫成「尚未接入」。

## A1.13 改動

維持 Cookery 原本的 Guidebook Extension API v1，不新增第二本實體指南書。

章節正式改名：

- 簡中：**森罗物语：烟火**
- 繁中：**森羅物語：煙火**
- 英文：**Kaleidoscope Grilling**

只保留三個清晰分類：

1. 玩法與取得方式
2. 烤串食譜
3. 調料與效果

「玩法與取得方式」有 6 個玩家向條目：

- 燒烤架
- 手工穿串
- 串盤與保存
- 作物與加工
- 榨油器與大缸
- 串譜與快速製作

每項使用不同實際物品／方塊圖示，不再用同一根串或同一個燒烤架重複佔位。

## 說明格式

正文改成短句操作步驟，不再出現：

- source result / ordered slots
- namespace id
- 「來源參考」
- 「素材預覽」
- 「尚未實作」
- 中英雙語開發註解

20 組固定串仍依 Java 1.1.1 的原順序保留，但只顯示玩家看得懂的「材料順序 → 烤製方式」。

## 圖示

A1.13 直接復用 Gameplay Core 目前已存在的正式資產，複製到指南 RP：

- 燒烤架
- 串盤
- 油菜種子
- 生牛肉串
- 榨油器
- 串譜
- 特製調料
- 魚腥草粉
- 圖騰粉
- 龍蛋粉
- 花椒

CI 逐一比較 SHA-256，避免指南圖示與正式物品圖分叉。

## 仍保留的宿主限制

Cookery 1.0.6 Guidebook API v1 的 `mechanicsByLocale` locale 過濾存在已驗證限制，因此條目名稱／分類／標題正常分 zh_CN、zh_TW、en_US，正文暫時用單一中文 fallback。

這是宿主 API 限制，不再用「繁中＋英文逐句重複」來掩蓋。

## 驗證

CI 會：

- 確認 A1.12 基線。
- 生成 A1.13 payload 與圖示。
- 驗證 3 分類、33 條目、20 配方、6 個玩法圖示互不重複。
- 阻止「素材預覽／來源參考／source id」等開發文字回流。
- 用官方 bridge Dash v1.2.0 編譯 BP/RP 並逐檔比較。
- 生成可導入的 guide-only mcaddon 與 brproject。

仍標記：

- `minecraft_tested=false`
- `bds_tested=false`

實機下一步主要看：手機／PC 的表單寬度、文字換行、圖示裁切、返回層級，以及 Cookery + Grilling 正式玩法包同時載入時的顯示。
