# A2.8.0 — 全分支整合測試版

本版整合 PR #1、#5、#6、#69、#74 的有效成果，以及先前未完成的放置外觀分支。沿用目前 main 的料理格言、油壺交易安全、64 種手持調料狀態和 PBR 防回退修復。早期 PR 的原始提案保留在 history/integrated-pr/；已由新版取代的舊 runtime／重建 workflow 不再重新啟用。

## 此版可測的內容

- 指南內建於煙火本體，仍為 Cookery 原指南的一個煙火章節；76 條目、77 配方變體，無額外指南 addon 或新實體書。
- 創造欄依最新 PR #74 沿用 Cookery 的 8 組 Equipment 群組，90 個既有可見項目，88 份內部／隱藏定義不曝光；不覆寫宿主圖示或語言。
- 39 個固定烤串、150 個逐口模型整合 Java 第一／第三人稱、左／右手 display 到獨立子骨骼，避免動畫與玩家 bound root 疊加。64 種手持調料剩餘量／變體保持原資料對應。
- 大缸實體邊框、獨立手持模型、廚具架手持及相關渲染修復一起整合；材質 render_method 保持一致。
- 放置的四瓶調料各自顯示內容：8 級剩餘量、8 種成品變體、未完成配料逐層顏色。顏色使用固定素材取樣後預烘色格，避免依賴某個 entity shader 的 overlay_color 行為。
- 放置油壺加入菜籽油／秘制辣椒油外觀及極品辣椒油發光顯示層；保留 Cookery 本體容器、碰撞、交互、油種與油量資料。
- 事件處理保留實際操作手、延後重驗、交易回復與單一穿串入口；無變更配方、營養公式、油容量或 world dynamic-property keys。

## 合併與發布原則

此包只由合併後 main 的 canonical workflow 建置。來源檢查、指南／分類／渲染規則、固定 Java 契約、Dash、來源與輸出逐檔對比及 ZIP 校驗成功後，才發布 prerelease。Tag 指向實際接受建置的 main commit，而不是另一個未經編譯的 PR head。不刪除舊測試版資產。

原先的 standalone guide 及競爭發布入口封存；可安裝成品只有本體 BP/RP，UUID 與 Cookery 1.0.6 依賴保持不變。早期 PR1/5/6 的核心數據由現代實作承接，另以原提案的20種穿串配方及兩組27物品數值檢查防回退，而非重新啟用被取代的腳本。

## 明確的驗收邊界

Minecraft / BDS / client visuals：**尚未實機驗收**。本版標為測試版，不稱為 Java 100% 等價正式版。

放置內容使用可丟棄、零碰撞的 transient 顯示助手，容器資料仍在原方塊／world keys。48 格以外釋放，每五 tick 限額更新，最多1024助手；移除失敗保留追蹤並重試，不靜默製造幽靈資料。大量容器時可見更新有延遲。

油壺覆蓋層依固定 Java Cookery 幾何製作，與 Bedrock 宿主的最終貼合、透明排序及發光在不同顯示模式下仍需實機畫面確認。配料顏色由本包可取得的素材於建置時取樣；第三方材料／客戶端替換材質使用既定後備色，並非伺服器即時讀取任意玩家材質包。

原版 Cookery 1.0.6 的指南正文 locale API 有限制時保留既有回退，不另外覆蓋宿主或要求相容 addon。

建議在備份世界依次確認：原 Cookery 指南煙火章節 → 共享創造群組 → 四種手持視角與進食 → 不同配料／剩餘量的四瓶 → 三種油壺外觀、破壞回收、重進世界。CI 與純資料測試不是這些遊戲操作的實機證明。
